## ✨ Features

| Feature | Description |
|--------|-------------|
| 🧮 **Auto-calculating Totals** | Line items update subtotal, tax, and grand total in real time |
| ➕ **Dynamic Item Rows** | Add or remove items on the fly |
| 💰 **Tax Support** | Configurable tax rate per invoice |
| 🌍 **Currency Selector** | Switch between multiple currencies |
| 🖼️ **Logo Upload** | Upload your business logo directly onto the invoice |
| ✅ **PAID Stamp Toggle** | Mark invoices as paid with one click |
| 🖨️ **Print-Ready Styling** | Optimised layout for clean printing or PDF export |
| 🔢 **Auto Invoice Numbers** | Invoice numbers auto-increment using localStorage |
| 👁️ **Live Preview** | See changes reflected instantly as you type |
| 🔄 **Reset Button** | Clear everything and start fresh |

## 🚀 Getting Started

No installs needed. Just open and use.

```bash
# Clone the repo
git clone https://github.com/KeabetsweMP/invoice-generator.git

# Open in your browser
cd invoice-generator
open index.html
```

Or just visit the **[live demo](https://invoice-generator-gamma-sand.vercel.app/)** directly. ✅

## 🎯 How to Use

1. Fill in your **business name, client details, and invoice date**
2. Upload your **logo** (optional)
3. Add **line items** with descriptions, quantities, and prices
4. Set your **tax rate** and select your **currency**
5. Toggle the **PAID stamp** if needed
6. Hit **Print** to export as PDF or send directly 🎉
